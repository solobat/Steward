## 关于 Steward v3

Steward v3 是基于 Chrome Extension Manifest V3 的命令启动器，支持在弹窗或当前页面内打开命令框，通过触发词快速访问书签、历史、标签、工作流与自定义搜索。

- **开源**：[GitHub - Steward](https://github.com/solobat/Steward)
- **安装**：Chrome 网上应用店（或从源码构建）
- **文档**：本站在线教程与隐私政策
