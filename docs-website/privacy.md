# 隐私政策

**生效日期**：以本页所载日期或扩展更新说明为准。  
**适用产品**：Steward v3（Chrome 扩展，Manifest V3）。

---

## 1. 数据存储与同步

- **配置与设置**：你的选项（如通用、插件开关、搜索、工作流、外观等）保存在 **Chrome 同步存储**（`chrome.storage.sync`）中。在已登录 Chrome 账户且开启同步的情况下，这些数据会随你的账户在设备间同步。
- **上次命令**：若开启「记忆上次命令」，扩展会将上次在命令框中使用的命令文本保存在 **Chrome 本地存储**（`chrome.storage.local`）中，仅用于下次打开时预填，不会上传到我们的服务器。
- **工作流、书签/历史/标签**：工作流内容存于 `chrome.storage.sync`。书签、浏览历史、标签页信息由扩展通过 Chrome 提供的 API（如 `chrome.bookmarks`、`chrome.history`、`chrome.tabs`）在**本地**读取并展示，我们**不收集、不存储、不上传**这些数据。

---

## 2. 我们不会收集的内容

- 我们**不运营**用于收集你个人数据的后端服务。
- 我们**不收集**你的书签内容、浏览历史、标签页、工作流内容或你在命令框中输入的具体查询。
- 扩展的代码与配置逻辑可在 [GitHub](https://github.com/solobat/Steward) 上查阅，便于你自行核对行为。

---

## 3. 第三方与链接

- 你通过命令框或工作流**主动打开**的网页（包括搜索引擎、维基等）受该网站自身隐私政策约束，我们不对其数据处理负责。
- 若在选项中配置了自定义搜索引擎或 URL，请求会发往你填写的域名，我们不会经手或存储这些请求内容。

---

## 4. 权限说明

扩展声明的 Chrome 权限仅用于实现功能，例如：

- **书签**：用于展示与搜索书签。
- **历史记录**：用于展示与搜索浏览历史。
- **标签页**：用于列出与操作标签（如打开、关闭、静音）。
- **存储**：用于保存你的设置与工作流（sync/local）。
- **活动标签页 / 当前窗口**：用于在「当前标签打开」等场景下更新正确标签。

上述数据均在本地或你的 Chrome 账户同步范围内处理，我们**不接收**这些数据。

---

## 5. 变更与联系

我们可能会更新本隐私政策，并在扩展或本页面注明生效日期。继续使用扩展即视为接受当时有效的版本。

如有与本隐私政策相关的问题，可通过项目仓库（如 GitHub Issues）联系维护者。
