# 外观与设置

## 选项页

点击扩展图标后可通过命令 `opt` 或 `ext` 打开选项页，或在 Chrome「扩展程序」中进入 Steward 的「扩展程序选项」。

选项页包含：**通用**、**插件**、**搜索**、**工作流**、**外观**、**关于**。

## 通用

- **速度优先**：开启后扩展在页面加载时即注入命令框，打开更快；关闭则首次按快捷键再注入以节省内存。
- **记忆上次命令**：下次打开命令框时预填上次使用的命令。

## 插件

可在此开启/关闭各命令（触发词）。关闭的插件不会在命令框中出现。

## 外观

- **主题**：浅色 / 深色 / 跟随系统。
- **强调色**：按钮、选中项等使用的颜色。
- **整体字号**：小 / 中 / 大。
- **列表密度**：紧凑 / 默认 / 宽松。
- **圆角**：直角 / 默认圆角 / 大圆角。
- **输入框高度**、**命令框背景色**、**列表标题/描述字号**：可进一步微调。
- **恢复默认主题**：一键恢复为默认外观。
- 修改后需点击「保存」；保存后重新打开命令框生效。

## 高级（若已提供）

- **导出配置**：下载当前配置为 JSON。
- **导入配置**：从 JSON 文件导入并合并到当前配置。
- **恢复默认配置**：将全部设置恢复为默认值。
