# 快捷键

## 打开命令框

| 快捷键（Mac） | 快捷键（Win/Linux） | 说明 |
|---------------|---------------------|------|
| ⌘K | Ctrl+K | 打开弹窗命令框 |
| ⌘J | Ctrl+J | 在当前页面内打开命令框 |

## 命令框内

| 按键 | 说明 |
|------|------|
| ↑ / ↓ | 在列表中上/下移动选中项 |
| Tab | 向下选中；Shift+Tab 向上选中 |
| Enter | 执行当前选中项 |
| ⌥ + Enter | 在当前标签页打开（适用于带 URL 的项） |
| ⇧ + Enter | 批量打开：从列表第一项到当前项中所有带 URL 的项，依次在新标签打开，最后一项在当前标签打开 |
| Esc | 有输入时清空输入（可配置「空命令」）；输入已空时关闭命令框 |

## 设置入口

在命令框中输入 `ext` 或 `opt` 可打开扩展/选项页；也可在 Chrome 的「扩展程序」中点击 Steward 的「详细信息」→「扩展程序选项」。
