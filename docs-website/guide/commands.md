# 命令与触发词

命令框采用「触发词 + 空格 + 过滤词」的形式，与 Alfred 类似。先输入触发词（可只输入前缀，从列表中选择），再输入空格与关键词即可过滤结果。

## 常用触发词

| 触发词 | 说明 |
|--------|------|
| bm | 书签 |
| his | 浏览历史 |
| tab | 标签页（含 tabp 置顶、tabm 静音、tabc 关闭等） |
| wf | 工作流 |
| meta | 当前页面元信息 |
| nav | 当前页面导航链接 |
| outline | 当前页面大纲（标题结构） |
| ext / opt | 扩展 / 选项页 |
| top | 常用网站 |
| url | 输入 URL 直接打开 |
| 计算式 | 直接输入算式可计算 |
| g / bd 等 | 搜索（需在设置中配置搜索引擎与默认关键词） |

## 使用方式

- **仅输入前缀**：如输入 `b`，会显示以 `b` 开头的命令（bm、bk、bks 等），选中一项回车即补全为该命令并进入对应列表。
- **触发词 + 空格**：如 `bm ` 进入书签列表，`bm 项目` 在书签中过滤「项目」。
- **无匹配时**：若配置了默认搜索引擎，会使用默认搜索对输入内容进行搜索。

在扩展**选项 → 插件**中可关闭不需要的触发词；**选项 → 搜索**中可管理搜索引擎与默认关键词。
