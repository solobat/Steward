# 搜索

## 自定义搜索

在 **选项 → 搜索** 中可配置：

- **搜索引擎列表**：每个引擎包含「关键词」「名称」和「URL 模板」。URL 中的 `{query}` 会被替换为用户的搜索词。
- **默认搜索关键词**：当输入不匹配任何命令时，将使用该关键词对应的引擎进行搜索。

例如关键词 `g` 对应 Google，输入 `g 关键词` 会打开 Google 搜索「关键词」；若设置默认关键词为 `g`，则直接输入 `关键词` 也会用 Google 搜索。

## 行为说明

- 输入形式为「关键词 + 空格 + 搜索词」时，使用对应关键词的引擎。
- 若输入不匹配任何命令且配置了默认搜索引擎，则使用默认引擎搜索整段输入。
